## Collaboration

This repo is developed by two people. Before pushing anything, read
[CONTRIBUTING.md](./CONTRIBUTING.md) for the branching convention and PR workflow.

Quick version:

- `main` is protected — no direct pushes, changes land through Pull Requests.
- Branch names are namespaced by initials: `sg/…` (Stefan), `in/…` (Ignacio).
- Every PR gets a review from the other person before merging.
